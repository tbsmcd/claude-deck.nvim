1. INTRODUCTION                                         *claude-terminals-intro*

claude-terminals.nvim runs Claude Code in Neovim terminals. Each terminal
shows its id, status and task title in the winbar, its cwd and session id
in the statusline, sends a desktop
notification when it waits for you, and lets Claude inspect the other
terminals with the `ct` command.

Requires Neovim 0.11 or later and `claude` on PATH. The hook script and
`ct` call `nvim --server`, so `nvim` must also be on the PATH seen by Claude
Code.

Optional (everything works without them):
- fzf-lua: pickers with split keys; falls back to |vim.ui.select()|
- nvim-tree.lua: file tree in focus mode; falls back to netrw
- zoxide: extra directories in |claude-terminals.pick_dir()|
- jq: pretty-prints the JSON of |claude-terminals.show_settings()|
- osascript (macOS, with lsappinfo for the frontmost app check) or
  notify-send (Linux) for desktop notifications, or your own
  `notify.notifier`

2. SETUP                                                *claude-terminals-setup*

>lua
    require("claude-terminals").setup({})
<
No keymaps are created. Map the functions below, for example:
>lua
    local ct = require("claude-terminals")
    vim.keymap.set("n", "<leader>cc", ct.toggle)
    vim.keymap.set("n", "<leader>cv", function() ct.new("right") end)
    vim.keymap.set("n", "<leader>cs", function() ct.new("below") end)
    vim.keymap.set("n", "<leader>cl", ct.list)
    vim.keymap.set("n", "<leader>cd", ct.pick_dir)
    vim.keymap.set("n", "<leader>cf", ct.fork)
    vim.keymap.set("n", "<leader>cr", ct.rename)
    vim.keymap.set("n", "<leader>co", ct.focus)
<

3. USAGE                                                *claude-terminals-usage*

                                                             *:ClaudeTerminals*
:ClaudeTerminals [{subcommand} [{args}]]
    Without a subcommand, same as `toggle`.

toggle()                                             *claude-terminals.toggle()*
    Outside a terminal, focus a visible terminal or open a new one. Inside a
    terminal, open a new one to the right.

new({where})                                            *claude-terminals.new()*
    Open a new terminal. {where} is "right" or "below" to split the current
    window, or nil to use the default placement:
    - inside a terminal: to the right
    - in an empty unnamed buffer: in place
    - otherwise: at the far right
    The new terminal uses the current terminal's cwd, or |getcwd()|.

list({opts})                                           *claude-terminals.list()*
    Pick a terminal, including hidden ones, and show it. With fzf-lua,
    <CR> opens with the default placement, <C-v> splits right and <C-s>
    splits below. {opts}.where sets the placement for |vim.ui.select|.

pick_dir({opts})                                   *claude-terminals.pick_dir()*
    Pick a directory and open a new terminal there. Candidates: current
    directory, cwds of terminals, children of `dir_roots`, and zoxide.

fork({where})                                          *claude-terminals.fork()*
    Open a new terminal that runs `claude --resume <session> --fork-session`
    for the current terminal's session.

rename()                                             *claude-terminals.rename()*
    Rename the current terminal's task.

focus()                                               *claude-terminals.focus()*
    Inside a terminal, open a new tab with file tree | editor | terminal and
    |:tcd| to the terminal's cwd. In that tab, close it and return to the
    original window.

show_settings()                               *claude-terminals.show_settings()*
    Show the Claude Code settings JSON (hooks and `ct` permissions) in a
    scratch buffer. Use it to add the hooks to your own settings when
    `claude_settings` is false.

show({id}, {where})                                    *claude-terminals.show()*
    Show terminal {id}.

Closing a terminal window with |:q| hides it; Claude keeps running.

                                                      *claude-terminals-windows*
Keys typed in a terminal go to Claude. Leave terminal mode with <C-q>
(`keymaps.normal_mode`) or <C-\><C-n>, then use |CTRL-W| commands. Moving
back into a terminal window enters terminal mode (`auto_insert`). Set
`keymaps.window = "<C-w>"` to run window commands from terminal mode (Claude
Code's CTRL-W, delete word, is then unavailable).

Opening a terminal does not resize other windows, even with 'equalalways'.

4. STATUS AND NOTIFICATIONS                            *claude-terminals-status*

Status comes from Claude Code hooks registered with `claude --settings`, so
your own settings are not modified. With `claude_settings = false`, add the
hooks to your own settings (|claude-terminals.show_settings()|); otherwise
status, notifications, task titles and fork do not work.

    New        started, `SessionStart`
    Running    `UserPromptSubmit`, `PostToolUse`
    Waiting    `Stop`                        (notifies)
    Needs you  `Notification`                (notifies)
    Exited     the process exited

A notification is skipped when Neovim has focus, the current window shows
that terminal and, on macOS, the terminal app is the frontmost app.

==============================================================================
5. THE CT COMMAND                                          *claude-terminals-ct*

Inside a terminal, `ct` is on PATH and Claude is told about it:

    ct list                 list terminals
    ct read <id> [count]    recent messages of a terminal (default 20)

Both are allowed without a permission prompt. `ct read` parses Claude Code's
transcript files, whose format is internal and may change.

6. CONFIGURATION                                      *claude-terminals-config*

    cmd                   command to start Claude  (default: { "claude" })
    claude_settings       pass hooks and `ct` permissions with
                          `claude --settings`  (default: true)
    title_width           max characters kept for the task title; the
                          winbar cuts it to fit  (default: 60)
    statusline            cwd and session id in the window's statusline;
                          false puts the cwd in the winbar  (default: true)
    width_ratio           width of a terminal opened at the far right
                          (default: 0.4)
    dir_roots             directories whose children `pick_dir()` offers
    zoxide                also offer zoxide directories  (default: true)
    labels                text for each status and `untitled`
    notify.enabled        (default: true)
    notify.states         (default: { "waiting", "attention" })
    notify.skip_when_watching  (default: true)
    notify.notifier       function({ title, subtitle, body, state, terminal })
    keymaps.normal_mode   terminal-mode key to leave terminal mode
                          (default: "<C-q>", false to disable)
    keymaps.window        terminal-mode prefix for window commands
                          (default: false, e.g. "<C-w>")
    auto_insert           enter terminal mode when entering a terminal
                          window  (default: true)
    picker                "auto", "fzf-lua" or "select"
    focus.tree            "auto", false or function(cwd)
    cli.enabled           put `ct` on PATH and allow it  (default: true)
    cli.system_prompt     tell Claude about `ct`  (default: true)

==============================================================================
7. HIGHLIGHTS                                     *claude-terminals-highlights*

The default status colors are based on the Okabe-Ito palette and differ in
lightness as well as hue, so they stay distinguishable with color vision
deficiencies. All are defined with `default = true` and can be overridden.

    ClaudeTerminalsIdle         gray
    ClaudeTerminalsRunning      sky blue
    ClaudeTerminalsWaiting      yellow
    ClaudeTerminalsAttention    vermillion
    ClaudeTerminalsExited       dark gray
    ClaudeTerminalsCwd          links to |hl-Directory|

==============================================================================
8. LIMITATIONS                                   *claude-terminals-limitations*

- Interrupting Claude does not fire `Stop`; the status stays Running until
  the next prompt.
- On macOS, switching tabs or panes inside the terminal app is not detected
  as losing focus.
